# RH-WEBSITE

Облачная социальная платформа RH, основанная на интерфейсе и функциях проекта MyMusic.

## Инфраструктура
- **Frontend:** Cloudflare Pages — `https://rh-website-9mb.pages.dev`
- **API:** Cloudflare Worker — `rh-website-api.rh-website.workers.dev`
- **Database:** Cloudflare D1 — `rh-website-db`
- **Admin owner:** `Raher` (роль `owner` назначается сервером при регистрации этого имени)

## Серверные функции
Регистрация и вход с серверными сессиями, профили, лента текстовых публикаций, редактирование и удаление своих публикаций, лайки, комментарии, подписки, уведомления, видео-предложения, личные сообщения, игровые комнаты и административная панель.

## Административная панель
Открой `#/admin` после входа под аккаунтом с соответствующими правами. Главный администратор `Raher` имеет полный доступ к управлению пользователями, публикациями, комментариями и настройками сайта. Его роль защищена от удаления и понижения.

## Медиафайлы
Загрузка изображений, видео и аудио пока отключена. Текущий Cloudflare Bridge проекта ограничен Workers, D1 и Pages; для пользовательских медиафайлов требуется отдельное объектное хранилище. Текстовые публикации уже сохраняются в D1.

## Разработка и проверка
GitHub Actions проверяет синтаксис браузерных скриптов и Worker. Отдельные smoke tests проверяют доступность API и Pages. Секреты не хранятся в репозитории.

Старые данные локального MyMusic не переносятся автоматически в D1. Проект RH-WEBSITE использует собственную отдельную базу. Защищённый Worker RH-LAUNCHER `raherauth` не используется и не изменяется.
