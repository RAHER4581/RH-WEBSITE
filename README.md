# RH-WEBSITE

Облачная социальная платформа RH, основанная на интерфейсе и функциях проекта MyMusic.

## Публичная версия
- **Сайт и API:** https://rh-website-api.rh-website.workers.dev
- **API health:** https://rh-website-api.rh-website.workers.dev/api
- **Database:** Cloudflare D1 — `rh-website-db`
- **Главный администратор:** `Raher` (роль `owner` назначается сервером при регистрации этого логина)

Сайт и API сейчас обслуживаются одним Cloudflare Worker. Интерфейс не зависит от локального сервера или локальной базы данных. Cloudflare Pages проект также создан, но текущая проверенная публичная версия размещена на Worker.

## Серверные функции
Регистрация и вход с серверными сессиями, профили, лента текстовых публикаций, редактирование и удаление своих публикаций, лайки, комментарии, подписки, уведомления, видео-предложения, личные сообщения, игровые комнаты и административная панель с ролями и модерацией.

## Административная панель
После регистрации под логином `Raher` открой раздел «Администрирование» или маршрут `#/admin`. Главный администратор имеет полный доступ к управлению пользователями, публикациями, комментариями и настройками. Его роль защищена от удаления и понижения.

## Медиафайлы
Загрузка изображений, видео и аудио пока отключена. Текущий Cloudflare Bridge проекта ограничен Workers, D1 и Pages; для пользовательских медиафайлов требуется отдельное объектное хранилище. Текстовые публикации и социальные данные сохраняются в D1.

## Разработка и проверка
GitHub Actions проверяет синтаксис клиентских скриптов и Worker, собирает воспроизводимый Worker bundle и проверяет доступность сайта, ассетов и API. Секреты не хранятся в репозитории.

Старые данные локального MyMusic не переносятся автоматически в D1. RH-WEBSITE использует собственную базу. Защищённый Worker RH-LAUNCHER `raherauth` не используется и не изменяется.
