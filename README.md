# RH-WEBSITE

RH-WEBSITE — облачная социальная медиаплатформа RH, переносимая из MyMusic.

## Архитектура
- Frontend: Cloudflare Pages.
- API: отдельный Cloudflare Worker `rh-website-api`.
- Database: Cloudflare D1.
- Интерфейс: русский язык, адаптация под мобильные устройства.

## Функции исходного проекта
Лента публикаций, профили, регистрация и вход, подписки, комментарии и реакции, уведомления, личные сообщения, игровые комнаты, видео-предложения и административная панель с ролями и модерацией.

## Важно
Старые данные браузера не становятся автоматически общей серверной базой. Серверные функции будут подключаться и проверяться поэтапно. До завершения миграции не считать все функции готовыми к публичному использованию.

Cloudflare ресурсы создаются отдельно для RH-WEBSITE. Секреты не хранятся в репозитории. Защищённый Worker RH-LAUNCHER `raherauth` не используется и не изменяется.
